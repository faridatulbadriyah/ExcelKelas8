# Excel Zone

Website pembelajaran Informatika Kelas VIII untuk SMP Negeri 18 Malang.

## Menjalankan

Buka `index.html` langsung di browser. Tidak membutuhkan proses build atau instalasi.

## Mengelola materi

Data 18 pertemuan berada di `js/main.js` pada konstanta `lessons`. Guru dapat mengganti judul dan deskripsi di sana. Progress belajar disimpan otomatis di `localStorage` browser masing-masing siswa.

## Hosting

Upload folder ini ke Netlify Drop, atau import repository ke Vercel/Netlify sebagai static site. Build command dikosongkan dan output directory menggunakan folder root.
